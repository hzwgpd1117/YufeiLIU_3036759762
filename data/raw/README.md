# Restricted source data

The course-provided CRSP CSVs are licensed inputs and are excluded from this public repository. Obtain Packages 02 and 03 through the course and place them at:

- `02_Monthly_Stocks_and_Factors/data/monthly_stock.csv`
- `02_Monthly_Stocks_and_Factors/data/F-F factors and RF.csv`
- `03_Daily_Stocks/data/daily_stock.csv`

The public French Mom series is stored at `reference/F-F_Momentum_Factor.csv`. The file's source vintage and download date are documented in the root README. The `data/raw` directory is a source manifest; the original course folder names are retained so their accompanying dictionaries remain usable.
